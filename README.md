# EDUGamification

Website scaffold for hosting interactive webpages used in online learning experiences.

## Hosting interactive webpages

1. Add your interactive HTML files to this repository (for example, in an `experiences/` folder).
2. Link those pages from `index.html`.
3. Enable **GitHub Pages** in repository settings and serve from the default branch.

The root `index.html` is the main landing page for published learning experiences.
