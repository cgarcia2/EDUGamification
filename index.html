How this site works

Add each learning experience to its own folder inside creations/, then register it in creations.json so it appears on the homepage.

1. Add a project

Create a folder like creations/my-activity/ and place your HTML files there.

2. Update the catalog

Add its title, description, and link in creations.json.

3. Publish with GitHub Pages

Enable Pages from the repository settings and use the main branch root as the source.
